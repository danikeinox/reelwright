Turn your website into Instagram Reels. On your own computer.

Reelwright is a free, open-source MCP server. Connect it to Claude, and it reads your site, renders branded Reels locally, and publishes to Instagram only after you approve them.

InstallView on GitHub

Local-first

Videos render on your machine with Remotion. Nothing is uploaded to a Reelwright server because there isn't one.

You approve everything

The AI cannot approve. You review the exact video and caption in a panel or terminal; changing either voids the approval.

Zero running costs

Free temporary Cloudflare tunnel for publishing, or bring your own S3/R2 bucket. Local voice-over with VoiceStudio.

Works with any MCP client

Claude Desktop, Claude Code and other MCP clients. The AI is whichever one you connect.

Private by design

Tokens stay in a 0600 file on your computer, are redacted from errors, and are never shown back to a browser or AI.

Open source (MIT)

Dependencies audited in CI, CodeQL, npm provenance. No accounts, no telemetry.

How it works

  1. Install Reelwright and run the guided setup.
  2. Add it to Claude with one command.
  3. Ask Claude: “Make a Reel from my website.”
  4. Review the result in the local panel, approve, and publish.

Install

npm install -g reelwright
reelwright setup
reelwright install-claude
# Claude Code:
claude mcp add reelwright -- reelwright serve

Node.js 22.12+

Questions

Is it really free?

Reelwright is MIT-licensed and has no service fee. Instagram's API is free to use. Remotion, the video engine, is free for individuals and teams of up to three people; larger companies need a Remotion licence.

Where do my tokens live?

Only in a private file on your computer (~/.reelwright/config.json, mode 0600). The optional remote dashboard never stores them.

Can the AI post without me?

No. There is no approve tool. Approval is tied to the SHA-256 of the video and the caption, and is given by you in the panel, a terminal, or a confirmation prompt.

Which Instagram accounts work?

Business or Creator accounts using the Instagram API with Instagram Login.

Does it need a server?

No. Everything runs on your computer. An optional dashboard you host yourself on your own Cloudflare account is available if you want remote access.
